# RedLens AI Camera

体验：[RedLens AI Camera](https://redlens-ai-camera.vercel.app) · 源码：[GitHub](https://github.com/Krisel304/redlens-ai-camera)

移动端优先的摄影创作 Demo：取景 → 构图 → 拍摄 → 诊断 → 调整 → 保存。

## 本地运行

需要 Node.js 20+，零运行时依赖。

```sh
npm run dev
# http://localhost:4173
npm test
npm run build
```

Vercel：构建命令 `npm run build`，产物目录 `dist`，无需环境变量。GitHub main 分支连接 Vercel 后提交自动部署。

## 已实现

- HTTPS/localhost 真实相机、镜头切换、拍摄；权限、超时及设备错误提示。
- 一键滑雪人像模拟取景、AI 辅助开关、三类场景共九个构图模板。
- 四张本地真实样例；可折叠图库，触摸、拖拽、滚轮、箭头浏览。
- 上传、照片详情、下载、浏览器原生文件分享（支持时）、删除。
- 真实像素统计诊断，选择建议进入编辑。
- 曝光、对比度、饱和度、色温、中心裁剪、旋转、按住对比、撤销/重做。
- IndexedDB 保存新版本，保留原图与父版本 ID。

## 能力边界

“AI 辅助”目前控制内置构图规则与本地像素分析，未接入云端视觉模型。智能场景语义识别未开放，入口会明确提示手动选场景；不会声称识别人物或拍摄意图。诊断分数为像素参考分，不是审美评分。真实相机仍需手机实测；HTTPS 和用户授权是必要条件。照片仅存在当前浏览器，清除站点数据会丢失；请下载重要照片。样例照片用于本项目展示，未授予第三方转载许可。

## 目录与版本

`src/app.js` 状态与交互；`src/views.js` 手机页面；`camera.js` 媒体流生命周期；`image.js` 像素诊断和编辑；`store.js` 本地存储；`config.js` 场景模板；`style.css` 响应式样式。

使用语义化版本；每个可验证阶段提交 Git，稳定交付创建标签。后续修改同步更新 CHANGELOG、DEVELOPMENT_LOG、TEST_CHECKLIST 和 KNOWN_ISSUES，禁止将未测试能力标为通过。

## 手机主导的产品界面（v1.4.0）

首页直接进入应用，相机、相册、照片详情、诊断、编辑均为手机布局。桌面访问同一套界面。没有 iframe 或模拟设备外框；`camera.html` 保留兼容入口。构图、删除、放弃编辑、说明与分享降级均使用应用内底部抽屉，不调用浏览器确认框。

相机首屏可完成拍摄，其他页内容独立滚动，主要操作固定底部。浏览器返回受应用路由管理；个人照片数据库保持不变，升级不清空已有作品。

### v1.4.1 构图交互

模板在取景区下方展开，无遮罩、背景锁定或模态弹窗。选中后继续预览、开关 AI、切换场景和直接拍照。详细指导位于取景区外。

### v1.4.2 iOS 相机版式

深色半透明界面，取景下方排列场景选择与白色快门，顶部集中 AI 和模拟入口。模板保持非模态，普通相机状态反馈不覆盖画面；相册、诊断与编辑同步使用深色材质。
